Always plan before implementing ENGINE_CHANGEs or strategy rewrites. Present the design for user review before writing code.

**Why:** User wants to review and align on the approach before code is written. Jumping straight to implementation risks building the wrong thing.
**How to apply:** For any significant code change (new strategy logic, engine modifications, multi-file refactors), use EnterPlanMode or present a structured plan and wait for approval before launching go-architect or writing code.
